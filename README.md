# FlexHubs Desktop

## Technology Stack

- Electron
- React
- TypeScript
- Vite
- Node.js
- Electron Forge

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

## Build / Package

```bash
npm run package
npm run make

# Mac: Intel + Apple Silicon (universal)
npm run make:mac

# Windows: 64-bit
npm run make:win
```

GitHub Actions builds both on every push to `main`. Download artifacts from the **Build Desktop App** workflow.
